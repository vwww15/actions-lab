
# Лабораторна робота — Actions

## Тема
Визначення дій (Actions) для управління станом.

## Мета роботи
Навчитися визначати типи дій у вигляді констант,
створювати об'єкти з полями type та payload
і писати генератори дій (action creators).

## Використані технології
- JavaScript (ES6+)
- Node.js
- Visual Studio Code

## Виконані завдання

### Завдання 1. Список покупок
Реалізовано:
- ADD_PRODUCT — додавання товару
- REMOVE_PRODUCT — видалення товару
- UPDATE_QUANTITY — оновлення кількості товару

### Завдання 2. Управління користувачами
Реалізовано:
- ADD_USER — додавання користувача
- REMOVE_USER — видалення користувача
- UPDATE_USER — оновлення даних користувача

### Завдання 3. Todo-список
Реалізовано:
- ADD_TODO — додавання завдання
- REMOVE_TODO — видалення завдання
- TOGGLE_TODO — зміна статусу виконання
- EDIT_TODO — редагування тексту завдання

## Запуск проєкту

У терміналі виконати:

    node actions.js

## Результат
Створено 10 генераторів дій.
Результати їхньої роботи перевірено в консолі Node.js.

## Висновок
У ході лабораторної роботи закріплено навички
створення констант типів дій та генераторів дій
для управління списками товарів, користувачів і завдань.
